# Full Application Security Assessment Report (`villeto-app`)

## 1. Executive Summary

An evidence-driven security assessment, STRIDE threat modeling exercise, and targeted remediation pass was conducted on **`villeto-app`** (`c:\Users\Sodiq Atiku\Documents\my-work-practice\Villeto\villeto-app`), a Next.js 16 (App Router) / React 19 / TypeScript B2B spend-management, procurement, bill-pay, expense, vendor-network, and multi-legal-entity frontend application.

- **Scope Boundary:** All SQL/database queries, password hashing, JWT/refresh-token issuance, server-side RBAC, payment initiation, and file storage orchestration reside in an external backend repository (`villeto-monolith`) configured via `API_BASE_URL` / `NEXT_PUBLIC_API_BASE_URL`. Next.js now exposes a dedicated BFF proxy Route Handler (`src/app/api/bff/[...path]/route.ts`) that keeps raw bearer JWTs server-side in sealed `HttpOnly` cookies.
- **Key Risks Identified & Remediated in `villeto-app`:** Stored XSS via same-origin `blob:` attachment previews and `.svg` / `data:` image URLs, unvalidated Google OAuth & notification redirect URLs, CSV formula injection and `unflatten()` prototype pollution, client-side bypass of `shouldChangePassword` rotation and incomplete reset/invite password complexity rules, missing `SameSite=Lax`/`Secure` attributes on auth cookies, permissive production CSP (`'unsafe-eval'`) and missing `Cache-Control: no-store` on authenticated routes, missing client upload MIME/size validation on avatars/logos/spreadsheets, weak `Math.random()` payment idempotency key generation, vulnerable dependencies (`next`, `axios`, `zod`, `vitest`, `xlsx@0.18.5`), and `sessionStorage` bearer JWT exposure (migrated to Next.js BFF `HttpOnly` session cookies).
- **Open External / Infrastructure Controls Requiring Follow-Up:** Mandatory server-side authorization/BOLA/entity-scoping/file-scanning/password-policy enforcement in `villeto-monolith`, provisioning `BFF_SESSION_SECRET` in production hosting, and resolving `8` remaining dev-only lint tooling advisories (`0` runtime vulnerabilities remain under `npm audit --omit=dev`). See [OUTSTANDING_BACKEND_INFRA_REQUIREMENTS.md](./OUTSTANDING_BACKEND_INFRA_REQUIREMENTS.md).

## 4. Threat Landscape Context (Citations & Limitations)

- **OWASP Top 10:2025:** Places **A01:2025 Broken Access Control** at #1 (now incorporating SSRF), **A02:2025 Security Misconfiguration** at #2, **A03:2025 Software Supply Chain Failures** at #3, and **A07:2025 Authentication Failures** at #7.
- **MITRE CWE Top 25 (2024–2025 editions):** **CWE-79 (Cross-Site Scripting)** ranks **#1** globally; **CWE-601 (Open Redirect)** and **CWE-1321 (Prototype Pollution)** appear in the extended "On the Cusp" dataset (~ranks 32–33 and ~67 respectively) due to high chaining utility (OAuth hijacking, RCE/DoS gadgets).
- **Verizon Data Breach Investigations Report (DBIR 2025):** Across analyzed security incidents (>22,000 incidents / thousands of breaches), credential misuse accounts for ~32% of all breaches, and ~88% of "Basic Web Application Attacks" breaches involved stolen credentials, reinforcing strict token protection, password rotation, and XSS prevention.
- **Limitations:** Industry breach percentages reflect broad cross-sector telemetry and do not directly measure Villeto's private production exploit likelihood; severity ratings in Section 3 are grounded directly in `villeto-app` exploitability and financial blast radius.
